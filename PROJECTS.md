# What I've Actually Built — AURA

*Daryl Crowchief (Smokey) · Independent AI-assisted builder*

I spend my working life around heavy equipment, so I tend to ask the same thing about software that I ask about machinery: **Does it actually do the job?**

AURA started as a personal idea: could I build an AI assistant that's useful to real people—not just one that gives impressive answers? That idea led to experiments with interfaces, memory, voice, system boundaries, and practical software.

## AURA — personal AI (in development)

**The idea:** A personal assistant that can hold a useful conversation, remember context with permission, work with selected tools, and stay under the user's control.

**Work explored so far:** Desktop interaction, voice, continuity, secure capability boundaries, and how AI should respond to what a person *means* rather than just their exact words.

**Status:** Active prototype/research work. A dependable, broadly usable release has **not** yet been established.

## AURA Maintenance — local-first maintenance prototype (paused)

**The problem:** People working with equipment need clear maintenance records, inspections, and usable workflows—not another complicated system to babysit.

**Work explored so far:** A Windows-based, local-first maintenance application, structured records, inspections and maintenance workflows, guarded changes, automated tests, and independent reviews.

**Status:** Substantial prototype and validation work completed. The work is paused at a preserved checkpoint; packaging and real-user acceptance are not complete. **This is not a commercial release.**

No employer-specific records, real fleet information, private source code, credentials, or internal screenshots are published here.

## What I've learned along the way

- **Start with the operator's real problem.** Fancy features don't help if they're difficult to use.
- **AI can help build the software.** I direct the work, learn the technical decisions, and rely on testing and review—not generated confidence.
- **Protect the data.** Clear permissions, local control, and avoiding changes to real records during tests matter.
- **A passing test isn't the finish line.** A person has to be able to use the result reliably.
- **Humour helps.** Sometimes the best feature request is: “Can my AI stop writing a novel and just shoot the shit?” 😄
